# DePLay 2.5.0

**Локальный медиаплеер для Windows: видео, фото и звук без облака и телеметрии.**

![Windows 10/11](https://img.shields.io/badge/Windows-10%20%2F%2011-0078D6?logo=windows&logoColor=white)
![WebView2](https://img.shields.io/badge/WebView2-required-2E7D32)
![Streamlink](https://img.shields.io/badge/Streamlink-8.6.3%20embedded-C1121F)
![Languages](https://img.shields.io/badge/languages-RU%20%7C%20EN%20%7C%20DE-blue)
![License](https://img.shields.io/badge/license-custom-lightgrey)

DePLay — настольное приложение для просмотра видео, изображений и прослушивания
звуковых дорожек. Локальные файлы не загружаются в интернет: веб-интерфейс
обслуживается локальным HTTP-сервером с одноразовым токеном, а сеть используется
только тогда, когда вы сами открываете ссылку на поток.

Версия хранится в [`version.txt`](version.txt), готовые сборки публикуются в **GitHub Releases**.

## Что нового в 2.5.0

- **Streamlink больше не нужно устанавливать отдельно.** Он поставляется внутри
  сборки (`streamlink\bin\streamlink.exe`) и вызывается по относительному пути.
- **MOV с четырьмя аудиодорожками работает**, включая несжатый PCM
  (`sowt`, `lpcm`, `in24`, `in32`, `fl32`, `fl64`, `twos`): дорожки
  конвертируются в WAV на лету.
- **`Uninstall.exe` действительно удаляет** приложение, процессы, ярлыки,
  реестр, настройки, кэш и временные папки, а не переустанавливает его.
- **Автотесты одной командой** — `pwsh .\tests\run-tests.ps1`.
- **Генератор фикстур на FFmpeg** для MP4/MOV с 1 и 4 дорожками (AAC и PCM).
- Исправлена нормализация ссылок Streamlink (`www.twitch.tv/канал` без схемы),
  чтение URL из `stderr`, качество потока и разбор аргументов командной строки.

## Возможности

### Видео

- Воспроизведение, пауза, перемотка ±2 секунды, покадровое перемещение.
- Скорость от 0.1× до 3×, зацикливание, громкость и полное отключение звука.
- Картинка в картинке (PiP) и полноэкранный режим.
- Таймлайн с буфером, перетаскиванием и предпросмотром кадра при наведении.
- Автоскрытие панелей и курсора во время просмотра; движение мыши возвращает
  управление.

### Звук

- **MP4/MOV/M4V:** разбор контейнера через MP4Box.js, список дорожек с языком,
  каналами, частотой и кодеком. Поддерживаются AAC, MP3 и несжатый PCM, включая
  многодорожечные MOV-файлы (4 дорожки PCM/AAC).
- **MKV/WebM:** извлечение AAC, MP3, Opus, FLAC и PCM на чистом JavaScript.
- **AVI:** извлечение PCM, MP2 и MP3.
- **Внешние дорожки:** MP3, WAV, M4A, AAC, OGG, FLAC и OPUS добавляются к видео
  и синхронизируются с ним.
- **Смешивание:** при включении встроенных дорожек оригинальный звук
  автоматически отключается, но его можно вернуть и слушать всё вместе.
- **Аудиорежим:** если видеокодек не поддерживается (например, Xvid/DivX в AVI),
  плеер извлекает звук и продолжает работать с таймлайном, скоростью и
  громкостью.
- Неподдерживаемые кодеки (AC-3, E-AC-3, DTS, TrueHD, Vorbis, WMA) честно
  помечаются в списке дорожек.

### Фото и GIF

- Галерея с миниатюрами, счётчиком и переходом между изображениями.
- Масштабирование колесом мыши, кнопками и жестами; перетаскивание, режимы
  «Вписать» и «1:1».
- Двойной клик по изображению, свайпы и pinch на сенсорных экранах.
- Анимированные GIF воспроизводятся как обычные изображения.

### Потоки

- Прямые ссылки на медиафайлы воспроизводятся сразу.
- HLS (`.m3u8`) играет через встроенный hls.js; сегменты и ключи идут через
  локальный прокси, поэтому нет проблем с CORS.
- Страницы вроде Twitch или YouTube live разрешаются через **встроенный
  Streamlink** — без отдельной установки.
- Ссылку можно перетащить в окно или передать аргументом командной строки.
  Адрес без схемы (`www.twitch.tv/канал`) тоже принимается.

### Интерфейс и приватность

- Тёмно-красная угловая тема, адаптивная раскладка, панели настроек и дорожек.
- Drag-and-drop файлов и ссылок.
- Настройки переживают перезапуск: они хранятся в нативном JSON, а не только в
  `localStorage`.
- Локальные файлы не покидают компьютер; сетевые запросы возникают только при
  открытии ссылок.

## Установка

### Вариант 1. Установщик (рекомендуется)

1. Откройте **GitHub Releases** и скачайте `DePLay-Setup.exe`.
2. Запустите установщик.
3. При необходимости выберите папку, ярлыки и ассоциации файлов.
4. Нажмите «Установить» и запустите DePLay.

По умолчанию приложение ставится в:

```text
%LOCALAPPDATA%\Programs\DePLay
```

Установщик:

- проверяет наличие **Microsoft Edge WebView2 Runtime** и предлагает скачать
  его, если runtime отсутствует;
- может зарегистрировать ассоциации для `.mp4`, `.m4v`, `.mov`, `.webm`, `.ogv`;
- создаёт ярлыки в меню «Пуск» и на рабочем столе;
- добавляет запись «Программы и компоненты» для удаления;
- **не требует установки Streamlink** — он уже внутри сборки.

> [!NOTE]
> Windows 11 не позволяет приложению молча назначить себя обработчиком по
> умолчанию. После установки откройте
> **Параметры → Приложения → Приложения по умолчанию → DePLay** и выберите
> нужные расширения либо используйте «Открыть с помощью → Выбрать другое
> приложение».

### Вариант 2. Портативная версия

1. Скачайте `DePLay-portable.zip` из Releases.
2. Распакуйте в любую папку.
3. Запустите `DePLay.exe`.

Портативной версии тоже нужен WebView2 Runtime. Встроенный Streamlink лежит в
подпапке `streamlink\` и работает после переноса папки на другой компьютер.
Если нужны ассоциации файлов и ярлык в «Пуск», запустите из папки приложения
`register.cmd`; для отмены — `unregister.cmd`.

### Требования

- Windows 10 или Windows 11 (x64 или x86).
- Microsoft Edge WebView2 Runtime. В современных версиях Windows он обычно уже
  установлен; установщик умеет это проверить.
- Права администратора не требуются: установка идёт в профиль пользователя,
  реестр — в `HKCU`.

### Тихая установка

```powershell
DePLay-Setup.exe /S /DIR="D:\Apps\DePLay" /NOREG /NOSHORTCUTS /NOLAUNCH
```

| Параметр | Значение |
|---|---|
| `/S` | Тихий режим без окон |
| `/DIR=<папка>` | Папка установки |
| `/NOREG` | Не регистрировать ассоциации файлов |
| `/NOSHORTCUTS` | Не создавать ярлыки |
| `/NOLAUNCH` | Не запускать приложение после установки |
| `/uninstall` | Удалить DePLay |

### Удаление

Через «Программы и компоненты», ярлык «Удалить DePLay» или вручную:

```powershell
"%LOCALAPPDATA%\Programs\DePLay\Uninstall.exe" /uninstall /S
```

`Uninstall.exe` можно запустить и без аргументов — двойной клик в Проводнике
включает режим удаления автоматически. Удаляются:

- файлы приложения и встроенный Streamlink;
- ярлыки и записи реестра `HKCU`;
- запущенные процессы DePLay;
- настройки, журналы и кэш WebView2 в `%LOCALAPPDATA%\DePLay`;
- временные папки `%TEMP%\DePLay*`.

Чтобы сохранить настройки при удалении (например, для переноса профиля),
запустите деинсталлятор с переменной окружения:

```powershell
set DEPLAY_UNINSTALL_KEEP_DATA=1
"%LOCALAPPDATA%\Programs\DePLay\Uninstall.exe" /uninstall /S
```

## Как пользоваться

### Открыть файл

Любой из способов:

- нажать кнопку открытия или клавишу **O**;
- перетащить файлы в окно;
- дважды кликнуть видеофайл в Проводнике, если DePLay назначен обработчиком;
- передать путь аргументом:

```powershell
.\DePLay.exe "C:\Videos\movie.mkv"
```

Видео открывается на первом кадре в состоянии паузы. Чтобы начать просмотр,
кликните по картинке или нажмите **Space**.

### Видео

- Одиночный клик по видео — пауза/воспроизведение, двойной — полноэкранный
  режим.
- Перетаскивание по таймлайну — переход к нужному месту.
- Кнопки скорости и выпадающий список FPS — точная настройка темпа и
  покадрового шага.
- Кнопка PiP выносит видео в отдельное окно поверх других.
- При простое панели скрываются; движение мыши или нажатие клавиши возвращает
  их.

### Звуковые дорожки

Откройте панель дорожек клавишей **T**:

- строка **«Звук видео»** соответствует оригинальной дорожке;
- встроенные дорожки контейнера показываются с кодеком, языком и параметрами;
- кнопка **«Включить все» / «Выключить все»** управляет встроенными дорожками
  сразу;
- у каждой дорожки есть свой регулятор громкости;
- внешние аудиофайлы добавляются клавишей **A** или перетаскиванием.

Для MOV/MP4 с четырьмя дорожками (например, запись с микрофона, Discord,
системного звука и приложения) все дорожки видны и включаются независимо.
PCM-дорожки перед воспроизведением автоматически упаковываются в WAV.

Если встроенные дорожки включены, оригинальный звук автоматически
приглушается. Верните переключатель «Звук видео», чтобы слушать дорожки вместе.

### Фото и GIF

- Колесо мыши — масштаб, перетаскивание — панорама.
- Двойной клик — увеличить/вернуть масштаб.
- `+` / `-` — плавный зум, `0` — сброс.
- Стрелки — предыдущее/следующее изображение.
- На тач-экране работают свайпы и pinch.

### Настройки

Клавиша **S** открывает панель настроек. Там меняются язык, громкость, скорость,
повтор, FPS и параметры Streamlink. Изменения сохраняются автоматически в:

```text
%LOCALAPPDATA%\DePLay\settings.json
```

Чтобы сбросить настройки, закройте DePLay и удалите этот файл — при следующем
запуске будут значения по умолчанию.

## Встроенный Streamlink

### Что это значит

Начиная с 2.5.0 Streamlink поставляется **вместе с плеером**. Пользователю не
нужно ничего скачивать, устанавливать или добавлять в `PATH`.

В папке приложения лежит портативная сборка:

```text
DePLay\
├── DePLay.exe
└── streamlink\
    ├── bin\streamlink.exe   ← лаунчер
    ├── Python\              ← встроенный Python и зависимости
    ├── pkgs\                ← плагины Streamlink
    ├── ffmpeg\              ← FFmpeg для потоков
    └── LICENSE.txt
```

Вся папка обязательна: `streamlink.exe` — это лаунчер, которому нужны соседние
`Python\` и `pkgs\`. Копировать один `.exe` недостаточно.

### Как DePLay ищет Streamlink

Порядок поиска:

1. путь, указанный в настройках DePLay (если задан);
2. встроенная копия рядом с `DePLay.exe`:
   `streamlink\bin\streamlink.exe`, `streamlink\streamlink.exe`,
   `bin\streamlink.exe`, `vendor\streamlink\…`, `third_party\streamlink\…`;
3. `%LOCALAPPDATA%\Streamlink\bin\streamlink.exe`;
4. `%APPDATA%\Streamlink\bin\streamlink.exe`;
5. `Program Files\Streamlink\bin\streamlink.exe`;
6. `Program Files (x86)\Streamlink\bin\streamlink.exe`;
7. `streamlink.exe` в `PATH`.

Встроенная версия имеет приоритет, поэтому перенос папки не ломает стримы.
Путь из настроек — переопределение для опытных пользователей (например, чтобы
проверить новую версию Streamlink).

### Настройка в DePLay

Откройте настройки (**S**) и найдите раздел **Streamlink**:

- **Качество:** `best`, `1080p`, `720p`, `480p`, `360p`, `worst`.
- **Путь:** оставьте пустым, чтобы использовать встроенную версию.
- **Статус:** показывает, найден ли Streamlink и по какому пути.

Параметры сохраняются в `settings.json` как `streamQuality` и `streamlink`.

### Как открыть ссылку

**Перетаскиванием.** Скопируйте ссылку и перетащите её в окно DePLay.

**Командной строкой:**

```powershell
.\DePLay.exe "https://www.twitch.tv/канал"
.\DePLay.exe "www.twitch.tv/канал"          # схема добавится автоматически
.\DePLay.exe "https://www.youtube.com/watch?v=ID"
.\DePLay.exe "https://example.com/stream.m3u8"
```

**Вторым запуском.** Если DePLay уже открыт, новый экземпляр передаст ссылку
работающему окну через именованный канал.

### Что происходит внутри

Для обычной страницы DePLay запускает встроенный Streamlink:

```text
streamlink\bin\streamlink.exe --stream-url "URL" "720p"
```

- таймаут — 45 секунд;
- берётся первый `http(s)`-URL из `stdout` или `stderr`;
- если это HLS, он открывается через локальный прокси;
- если Streamlink не найден или завершился ошибкой, показывается
  локализованное сообщение, а подробности пишутся в журнал.

Streamlink использует собственный конфиг `%APPDATA%\streamlink\config`, поэтому
авторизацию и дополнительные параметры можно задать там — DePLay их не
переопределяет.

### Проверка без окна

```powershell
.\DePLay.exe --resolve-stream "https://www.youtube.com/watch?v=ID"
```

Программа напечатает найденный `streamlink.exe` и прямой URL потока, затем
`RESULT: PASS` или `RESULT: FAIL`. Это удобно для диагностики.

### Если ссылка не открывается

| Симптом | Что проверить |
|---|---|
| «Streamlink не найден» | На месте ли папка `streamlink\bin\streamlink.exe`; не задан ли в настройках неверный путь |
| Команда завершилась ошибкой | Запустите `streamlink\bin\streamlink.exe --stream-url "URL" best` вручную |
| Поток устарел | Прямые ссылки часто живут недолго — откройте страницу заново |
| Нет качества `1080p` | Выберите `best` или доступное разрешение |
| HTTPS не работает | Нужна поддержка TLS 1.2 в системе |
| Ошибка CORS у HLS | Используйте ссылку целиком; DePLay сам проксирует плейлист и сегменты |

## Поддерживаемые форматы

| Категория | Форматы | Примечание |
|---|---|---|
| Видеоконтейнеры | MP4, M4V, MOV, WebM, MKV, AVI, OGV | Воспроизведение видео зависит от кодеков WebView2/Edge |
| Встроенный звук MP4/MOV/M4V | AAC, MP3, PCM (`lpcm`, `sowt`, `twos`, `in24`, `in32`, `fl32`, `fl64`, `ipcm`, `raw `) | PCM конвертируется в WAV на лету; поддерживаются многодорожечные MOV |
| Встроенный звук MKV/WebM | AAC, MP3, Opus, FLAC, PCM | AC-3, E-AC-3, DTS, TrueHD, Vorbis не поддерживаются |
| Встроенный звук AVI | PCM, MP2, MP3 | AC-3, DTS, WMA не поддерживаются |
| Внешний звук | MP3, WAV, M4A, AAC, OGG, FLAC, OPUS | Добавляется к видео как отдельная дорожка |
| Изображения | PNG, JPEG, GIF, WebP, AVIF, BMP, SVG | GIF анимируется, остальные — с зумом и панорамой |
| Потоки | HTTP(S), HLS (`.m3u8`), страницы через Streamlink | HLS идёт через локальный прокси |

> [!IMPORTANT]
> DePLay не содержит собственных видеокодеков. Если WebView2 не умеет
> декодировать видео (например, Xvid/DivX в AVI), плеер попробует включить
> аудиорежим, но не сможет показать картинку. Для гарантированного
> воспроизведения используйте H.264/AAC в MP4 либо конвертируйте файл.

## Командная строка

```powershell
DePLay.exe "C:\Videos\movie.mp4"
DePLay.exe "https://example.com/stream.m3u8"
DePLay.exe --selftest
DePLay.exe --version
DePLay.exe --resolve-stream "https://www.twitch.tv/канал"
DePLay.exe --remote-debugging-port=9222
```

| Параметр | Назначение |
|---|---|
| `<путь>` | Открыть локальный файл |
| `<URL>` | Открыть ссылку или страницу через встроенный Streamlink |
| `--selftest` | Headless-проверка сборки, URL, Streamlink и локального сервера; код возврата 0 — успех |
| `--version` | Показать версию |
| `--resolve-stream <URL>` | Разрешить страницу в прямой URL через Streamlink и выйти |
| `--remote-debugging-port=<порт>` | Диагностика веб-части: DevTools WebView2 на `http://127.0.0.1:<порт>/json` |

## Сборка из исходников

Проект собирается **без Visual Studio и без .NET SDK**. Нужны только PowerShell
5.1 и `csc.exe` из .NET Framework 4.x, который входит в Windows. Для встраивания
Streamlink нужен интернет (скачивается один раз и кэшируется).

```powershell
.\build.ps1
```

Или из `cmd.exe`:

```bat
build.cmd
```

### Цели сборки

| Команда | Результат |
|---|---|
| `.\build.ps1 -Target app` | Портативное приложение в `build\app` |
| `.\build.ps1 -Target payload` | Приложение + `build\payload\DePLay.Payload.zip` |
| `.\build.ps1 -Target setup` | Payload + `build\setup\DePLay-Setup.exe` |
| `.\build.ps1 -Target installer` | Публикация артефактов в `dist\` |
| `.\build.ps1` / `-Target all` | Полная сборка |
| `.\build.ps1 -Target clean` | Удалить `build\` и `dist\` |
| `.\build.ps1 -Target app -SkipStreamlink` | Сборка без загрузки Streamlink (офлайн/быстрые тесты) |

### Встраивание Streamlink

1. `build.ps1` запрашивает последний релиз
   [`streamlink/windows-builds`](https://github.com/streamlink/windows-builds).
2. Скачивается **портативный ZIP** (не `.exe` — это установщик).
3. Архив распаковывается в `build\cache\streamlink` и переиспользуется при
   следующих сборках.
4. В `build\app\streamlink\` копируется вся папка (`bin`, `Python`, `pkgs`,
   `ffmpeg`).
5. Payload-проверка убеждается, что `streamlink/bin/streamlink.exe` попал в
   архив установщика.

Кэш не коммитится: он создаётся при сборке и указан в `.gitignore`. Если
интернета нет, используйте `-SkipStreamlink` — плеер соберётся, но стримы
через страницы будут недоступны до появления встроенной копии.

### Артефакты

```text
dist\
  DePLay-Setup.exe          — установщик
  DePLay-Setup.exe.sha256   — контрольная сумма и версия
  DePLay-portable.zip       — портативная сборка
```

Размер полной сборки — около 87 МБ: большую часть занимают встроенный
Streamlink и FFmpeg.

### GitHub Desktop

Репозиторий подготовлен для обновлений через GitHub Desktop:

- `build\`, `dist\`, `tests\fixtures\generated\` и `tests\.tmp\` игнорируются;
- кэш Streamlink (`build\cache\streamlink`, `vendor\streamlink*`) игнорируется;
- логи, `settings.json`, `language.txt`, `node_modules\` и файлы IDE/ОС
  игнорируются;
- крупные бинарники не коммитятся, а скачиваются при сборке.

Не добавляйте в Git содержимое `build\` и `dist\` — это приводит к конфликтам
и раздуванию истории.

## Автотесты

Все проверки запускаются одной командой:

```powershell
pwsh .\tests\run-tests.ps1
```

Скрипт печатает `PASS`/`FAIL` по каждому шагу и итог `ALL TESTS PASSED` или
`TESTS FAILED`. Код возврата 0 — успех.

Что проверяется:

1. **Сборка** портативного приложения (`build\app`).
2. **Контейнеры и извлечение звука** — `tests/media.test.js` (MKV/WebM/AVI).
3. **Генерация фикстур** — FFmpeg создаёт MP4/MOV с 1 и 4 дорожками.
4. **WAV/PCM** — `tests/wav.test.js` (заголовок, каналы, 16/24 бита).
5. **MP4/MOV с 4 дорожками** — `tests/mp4-audio.test.js`, включая
   восстановление PCM-дорожек, которые MP4Box считает `metadata`.
6. **Self-test приложения** — `DePLay.exe --selftest`: файлы, WebView2,
   локальный сервер, `Range`, токен, прокси, URL и встроенный Streamlink.
7. **Streamlink** — `tests/streamlink.test.ps1` с фиктивным
   `streamlink.exe`: URL со схемой и без, ошибка разрешения, отсутствие
   Streamlink.
8. **Установка и удаление** — `tests/uninstall.test.ps1`: тихая установка во
   временную папку, запуск `Uninstall.exe /S` без `/uninstall`, проверка
   очистки файлов и пользовательских данных.

Полезные ключи:

```powershell
.\tests\run-tests.ps1 -SkipBuild        # не пересобирать приложение
.\tests\run-tests.ps1 -WithStreamlink   # скачать/встроить Streamlink при сборке
.\tests\run-tests.ps1 -Keep             # сохранить временные папки для отладки
```

Отдельные проверки:

```powershell
node .\tests\media.test.js
node .\tests\wav.test.js
node .\tests\mp4-audio.test.js
.\tests\streamlink.test.ps1
.\tests\uninstall.test.ps1
.\build\app\DePLay.exe --selftest
```

Для изоляции тестов используются переменные окружения:

| Переменная | Назначение |
|---|---|
| `DEPLAY_DATA_DIR` | Папка настроек/логов/WebView2 вместо `%LOCALAPPDATA%\DePLay` |
| `DEPLAY_TEST_MODE=1` | Установщик не трогает реестр, ярлыки и процессы |
| `DEPLAY_UNINSTALL_KEEP_DATA=1` | Не удалять настройки при деинсталляции |
| `DEPLAY_STREAMLINK_IGNORE_SYSTEM=1` | Игнорировать системный Streamlink (проверка встроенного) |

## Тестовые медиафайлы

Фикстуры лежат в `tests/fixtures/`. Они **не коммитятся**: генерируются
локально за пару секунд и не раздувают репозиторий.

```text
tests\fixtures\
├── fake-streamlink.cs          фиктивный streamlink.exe для тестов
├── generate-media.py           генератор (Python + FFmpeg)
├── generate-media.sh           генератор (Bash/WSL)
├── README.md                   структура и ручной чек-лист
└── generated\                  создаётся генератором (в .gitignore)
    ├── sample_video.mp4        H.264 + AAC
    ├── sample_video.mov        H.264 + AAC
    ├── multi_audio_4x_aac.mov  H.264 + 4 AAC (Microphone/Discord/Windows/Apps)
    ├── multi_audio_4x_pcm.mov  H.264 + 4 PCM s16le
    ├── multi_audio_4x_mp4.mp4  H.264 + 4 AAC
    └── audio_only.m4a          только звук
```

Генерация:

```powershell
# Python (Windows)
python .\tests\fixtures\generate-media.py --force

# Bash (Linux/macOS/WSL)
bash tests/fixtures/generate-media.sh --force
```

Нужен `ffmpeg` в `PATH`. В полной сборке DePLay он уже есть:

```powershell
$env:PATH = "$PWD\build\app\streamlink\ffmpeg;$env:PATH"
```

`run-tests.ps1` делает это автоматически, если находит FFmpeg в
`build\cache\streamlink\ffmpeg` или `build\app\streamlink\ffmpeg`. Если
FFmpeg или Python не найдены, шаг генерации пропускается, а MP4/MOV-тест
сообщает об отсутствии фикстур.

Ручной чек-лист (подробнее в `tests/fixtures/README.md`):

1. Открыть `multi_audio_4x_pcm.mov` — видны 4 дорожки, каждая играет.
2. Открыть `multi_audio_4x_aac.mov` и `multi_audio_4x_mp4.mp4` — 4 дорожки с
   именами и языками.
3. Переключение дорожек не рассинхронизирует звук с видео.
4. `sample_video.mov` и `sample_video.mp4` ведут себя одинаково.

## Диагностика

### Где лежат данные

| Что | Путь |
|---|---|
| Настройки | `%LOCALAPPDATA%\DePLay\settings.json` |
| Язык | `%LOCALAPPDATA%\DePLay\language.txt` |
| Журнал | `%LOCALAPPDATA%\DePLay\DePLay.log` |
| Журнал установщика | `%LOCALAPPDATA%\DePLay\setup.log` |
| Данные WebView2 | `%LOCALAPPDATA%\DePLay\WebView2` |
| Установка по умолчанию | `%LOCALAPPDATA%\Programs\DePLay` |

Все эти данные удаляются деинсталлятором (кроме случая
`DEPLAY_UNINSTALL_KEEP_DATA=1`). Для тестов и портативного профиля папку можно
переопределить переменной `DEPLAY_DATA_DIR`.

### Частые проблемы

| Проблема | Решение |
|---|---|
| Приложение не запускается | Установите WebView2 Runtime; проверьте журнал |
| Чёрный экран, но звук есть | Видеокодек не поддерживается WebView2; включился аудиорежим |
| MOV: дорожки есть, но «кодек не поддерживается» | Обновитесь до 2.5.0 — PCM-дорожки конвертируются в WAV; проверьте журнал |
| Нет звука в MKV/AVI | Кодек AC-3/DTS/WMA и подобные не извлекаются; смотрите пометку в списке дорожек |
| Видео открылось на паузе | Это нормально: кликните по видео или нажмите `Space` |
| Файл не открывается из Проводника | Назначьте DePLay обработчиком в параметрах Windows или запустите `register.cmd` |
| Ссылка не открывается | Проверьте папку `streamlink\` и журнал; используйте `--resolve-stream` |
| После удаления остались данные | Проверьте `DEPLAY_UNINSTALL_KEEP_DATA`; запустите `Uninstall.exe` без этой переменной |
| После переноса портативной папки пропали ассоциации | Запустите `register.cmd` заново |
| SmartScreen или антивирус предупреждает | Сборка не подписана; проверьте SHA-256 из релиза |

Проверка целостности сборки:

```powershell
Get-FileHash .\dist\DePLay-Setup.exe -Algorithm SHA256
Get-Content .\dist\DePLay-Setup.exe.sha256
```
