# DePLay

DePLay — локальный медиаплеер для Windows. Он открывает видео, фотографии и
звуковые файлы с компьютера, а также ссылки на трансляции и обычные видео.
Интерфейс работает на WebView2, поэтому не требует установки отдельного
браузера или медиаплеера.

## Возможности

- **Видео, фото и звук в одном окне.** Локальные файлы открываются перетаскиванием
  или через диалог выбора файла.
- **Полноэкранный просмотр с плавным зумом.** Для изображений доступны масштаб
  колесом мыши, панорамирование перетаскиванием, быстрое приближение двойным
  кликом и сброс масштаба.
- **Покадровая перемотка.** Шаг кадра рассчитывается по частоте кадров видео;
  частоту можно задать вручную в настройках.
- **Встроенные звуковые дорожки и живой микс.** Дорожки извлекаются из
  контейнера прямо на устройстве. Несколько дорожек можно включить одновременно:
  они смешиваются и синхронизируются с видео. У каждой дорожки свой регулятор
  громкости.
- **Режим трансляции.** Для живых потоков показываются название эфира, время с
  начала трансляции, задержка от эфира, кнопка «Догнать эфир» и выбор качества.
- **Открытие ссылок на трансляции и обычные видео.** Ссылки на каналы, VOD и
  клипы обрабатываются через Streamlink. Прямые ссылки на медиафайлы и
  HLS-плейлисты воспроизводятся без него.
- **Перетаскивание ссылок.** Ссылку можно перетащить в окно, в том числе во
  время воспроизведения. Поддерживаются текстовые ссылки и ярлыки Windows.
- **Поддерживаемые форматы:**
  - видео — MP4, M4V, MOV, WebM, OGV, MKV, AVI;
  - изображения — PNG, JPEG, GIF, WebP, AVIF, BMP, SVG;
  - звук — MP3, WAV, M4A, AAC, OGG, OGA, FLAC, Opus;
  - потоки — HLS (`.m3u8`) и прямые медиассылки.

## Установка и запуск

Скачайте установщик из раздела Releases и запустите его. При установке можно
выбрать папку; ярлык появится в меню «Пуск». Портативная сборка из того же
раздела не требует установки: распакуйте архив и запустите `DePLay.exe`.

Для работы интерфейса нужен Microsoft Edge WebView2 Runtime. На современных
версиях Windows он уже установлен; если окно не открывается, установите Runtime
с сайта Microsoft.

Запуск с файлом или ссылкой из командной строки:

```bat
DePLay.exe "C:\Videos\movie.mkv"
DePLay.exe "https://www.twitch.tv/channel"
DePLay.exe "https://www.twitch.tv/videos/123456789"
```

Ссылку без схемы (`www.twitch.tv/channel`) плеер дополнит до `https://`.
Если приложение уже запущено, новый файл или ссылка откроются в существующем
окне.

## Использование

Перетащите файлы или ссылку в окно либо нажмите «Выбрать файл». Видео
открывается в режиме видео, изображения — в режиме изображения, живые
трансляции — в режиме трансляции. Обычные видео по ссылке, включая VOD,
открываются в обычном видеорежиме с перемоткой и управлением скоростью.

### Горячие клавиши

| Действие | Клавиши |
|---|---|
| Играть / пауза | `Space`, `K` |
| Назад / вперёд на 2 секунды | `←`, `→` |
| Покадрово | `,`, `.` |
| Покадрово с Shift | `Shift` + `←` / `→` |
| Скорость | `[`, `]` |
| Громкость | `↑`, `↓` |
| Без звука | `M` |
| Полный экран | `F` |
| Настройки | `S` |
| Звуковые дорожки | `T` |
| Открыть файл | `O` |
| Добавить звук | `A` |
| Картинка в картинке | `P` |
| Повтор видео | `L` |
| Догнать эфир | `C`, `End` |
| Начало | `Home` |
| Зум изображения / сброс | `+`, `−`, `0` |
| Закрыть панель | `Esc` |

В режиме изображения колесо мыши меняет масштаб, двойной клик приближает,
перетаскивание перемещает изображение, а `0` возвращает исходный вид.
В режиме трансляции ускорение недоступно: доступно только замедление
(до 0.1×), чтобы не отставать от эфира ещё сильнее.

### Режим трансляции

Панель трансляции показывает название эфира, время с начала трансляции и
задержку относительно актуального момента. Под ней находится полоса перемотки
эфира: она показывает, насколько воспроизведение отстало от live-края, и
позволяет вернуться к более раннему моменту в пределах DVR-окна, которое ещё
отдаёт провайдер (у Twitch это около 30 секунд). Кнопка «Догнать эфир» (или
`C` / `End`) переходит к актуальному краю потока без перезапуска.

Список качеств строится по данным Streamlink для конкретного стрима или VOD,
поэтому в нём могут быть как привычные `720p` и `1080p`, так и `720p60`,
`audio_only`, `chunked` или `source`. По умолчанию выбрано `BEST`. Смена
качества происходит без возврата на стартовый экран: громкость и состояние
звуковых дорожек сохраняются, для VOD удерживается позиция, а у эфира —
текущее отставание от live-края. Если выбранное качество недоступно, плеер
включает лучшее доступное и показывает уведомление.

### Звуковые дорожки

Откройте панель «Звуковые дорожки» (`T`). Встроенные дорожки извлекаются из
контейнера и называются по реальному тегу `title`; если тега нет, используются
имена `Audio line 1`, `Audio line 2` и так далее. Дорожки можно включать и
выключать независимо, менять их громкость и добавлять внешние звуковые файлы.
При выключении всех дорожек наступает полная тишина.

## Настройки

Панель настроек открывается кнопкой в плеере или клавишей `S`.

- **Язык интерфейса** — русский, английский или немецкий; применяется сразу.
- **Частота кадров** — шаг покадровой перемотки. Значение `Авто` определяет
  частоту по видео.
- **Зациклить видео** — повторять файл бесконечно.
- **Сбросить настройки по умолчанию** — возвращает громкость, скорость, повтор,
  частоту кадров и качество потока к исходным значениям.

Громкость, скорость, повтор, частота кадров и выбранное качество сохраняются
между запусками. Файлы при этом остаются на устройстве: плеер не загружает их
в сеть.

## Требования

- Windows 10 или Windows 11.
- Microsoft Edge WebView2 Runtime.
- Streamlink — для ссылок на страницы трансляций и VOD. В официальных сборках
  он поставляется рядом с `DePLay.exe` и определяется автоматически. Если
  Streamlink установлен отдельно, плеер найдёт его в стандартных папках или в
  `PATH`. Для работы Streamlink нужен доступ в интернет.
- Прямые ссылки на медиафайлы и HLS-плейлисты работают без Streamlink.

## Сборка из исходников

Проект собирается без Visual Studio и .NET SDK: используется `csc.exe` из
.NET Framework и PowerShell.

```powershell
.\build.ps1
```

Скрипт соберёт приложение, подготовит payload и установщик в `dist\`.
Отдельные цели: `-Target app` (портативная папка), `-Target payload`,
`-Target setup`, `-Target installer`, `-Target clean`. Ключ `-SkipStreamlink`
собирает приложение без загрузки Streamlink.

Полный прогон автотестов:

```powershell
.\tests\run-tests.ps1
```

Подробности о зависимостях, структуре сборки и диагностике — в
[`docs/BUILD.md`](docs/BUILD.md).
